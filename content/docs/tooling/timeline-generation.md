### 3.4. Mermaid Timeline diagram

[Mermaid Timeline diagram](https://mermaid.js.org/syntax/timeline.html) is a diagram type designed specifically for
chronological data. Events are grouped into `section`s (eras), each time period can carry multiple events, and a second
`:` separator adds a sub-point that appears below the main event label — useful for brief context.

The vertical connector lines between the timeline spine and the event boxes show arrowheads by default. These can be
suppressed by injecting `line { marker-end: none !important; }` via the `themeCSS` config option in the YAML
frontmatter.

{{< codeExpand src="assets/ai-history-chronology-timeline.mmd" lang="mermaid"
title="View Mermaid source code for Timeline diagram" >}}

{{< img src="assets/ai-history-chronology-timeline.svg" alt="Mermaid Timeline Diagram Visualization" >}}

The diagram reads left to right (oldest to newest), making it intuitive to follow the progression of AI history. Each
era gets a distinct color, and sub-points provide just enough context without cluttering the main labels.

## 4. Conclusion

I didn't find a perfect solution to generate a timeline from markdown files, I think I will go Mermaid ishikawa diagram
as it offers a good balance between readability and compactness.
